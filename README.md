# Temario Espacial

Repositorio compuesto de una colección de fuentes académicas, técnicas de análisis geoespacial, guías de utilización de software geoespacial, y tutoriales de programación utilizando bibliotecas y métodos espaciales.

La intención de este repositorio es que funcione como la base para la enseñanza del pensamiento espacial, así como su praxis digital. Se utilizarán sistemas de información geográfica como QGIS, *scripting* en Python y R (implementando librerías geoespaciales y estadísticas), así como una colección de software de análisis económico y geoespacial.

El temario fué escrito por estudiantes de urbanismo y su fin es estudiar fenómenos económicos, morfológicos, sociales, y políticos dentro de diferentes ciudades, así como la visualización de propuestas de planeación y gestión urbana, pero se pueden aplicar muchos de los métodos y técnicas vistas hacia diferentes aspectos del análisis geoespacial.
